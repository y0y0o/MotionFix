# MotionFix 感知实验 —— 使用说明

## 这是什么
用人的判断验证"修脚后是否更自然"(导师第7点 physical plausibility 的另一半),
并检验"Jitter 低 = 看起来更自然"这个整条权衡叙事底下未验证的假设。

## 怎么做
1. 确认 `clips/` 里有 48 段 mp4(12 动作 × 4 条件:orig/deskate/gauss/v19)。
2. 浏览器打开 `rating.html`(直接双击即可,不需要服务器)。
3. 输入代号 → 逐对看两段动画,选"哪个更自然"(← A / 空格 分不清 / → B)。
4. 做完点"导出结果 CSV",文件名 `perceptual_<代号>.csv`。
5. 把每个人的 CSV 收集到 `responses/` 目录。

## 建议规模
≈10 人,每人 36 对(12 动作 × 3 类对比),约 8–12 分钟。

## 对比设计(每类都拿交付点 v19 和另一方盲比)
- orig    vs v19 : 修正整体是否更自然
- deskate vs v19 : 学习平滑器相对纯物理有没有可感知价值(决定交付纯物理还是带学习)
- gauss   vs v19 : 学习平滑器和高斯能不能被人分辨

## 分析
收齐 CSV 后:
    python analysis/perceptual_analysis.py
输出各对比 v19 偏好率 + 二项检验 + 对照动作注意力检查。

## 预期与解读
- 若 deskate_vs_v19 **不显著** → 学习平滑器无可感知优势 → 支持"学习不必需"主结论,
  可考虑直接交付 deskate_ik(更锋利)。
- 若 v19 在 orig_vs_v19 上显著更自然 → 修正有效的人证。
- 对照动作(FSR=0)应接近平局;若某人对照全是明确选择,其数据可能不认真。
